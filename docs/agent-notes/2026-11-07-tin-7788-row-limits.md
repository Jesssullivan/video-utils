## Decisions in this draft

- The limits count in the digest. The catalog row and the pinned graph hold the same keys, so a change to a limit moves
  all three, as a change to a parent does.
- 3h on every stage task, with no estimate per stage. The child limit is 2 hours, and a fix runs inside the failed task's
  limit. No stage duration was measured for this.
- `voice` takes 1 retry and the others 2, because a repeat can spend on a GPU. A worker death between a round and its
  event resumes only on a retry of that run, so a stage task needs at least 1.
- The guard and the operator tasks keep the SDK's 60 seconds. They run short reads, and a 60 second stop on a guard fails
  closed. No duration was measured for them either.
