## Change

- `condense/BUILD.bazel` (new package):
  - `//condense:condense`: py_library of `condense/*.py`.
  - `//condense:stdlib_test`: runs `condense/tests/stdlib_smoke.py` on the hermetic CPython 3.12 with no pip hub.
    It imports every module that reaches no numpy import. Computed from the import graph: 11 modules imported, and
    avsync, check and `__main__` are left out. It also loads the example `talk.toml` and checks EDL quantisation,
    the source/output time map, filler detection and SRT/VTT captions.
  - `//condense:pytest`: runs the condense pytest suite (`condense/tests/bazel_pytest.py`) on the dev shell's
    python3 from PATH, with `VIDEO_UTILS_BIN` from `//src:video-utils`. It is tagged `requires-host-tools` and
    `no-sandbox`, so hosted CI excludes it. Command:
    `nix develop .#condense -c bazel test //condense:pytest --config=host-tools`.
- `tests/BUILD.bazel`: the unittest modules take `//condense:all_files` as data. condense/ is now its own
  package, so `//:repo_data` no longer covers it.
- `tests/test_bazel_graph_s3.py`: lists condense as an owned package and a required graph file (13 to 14), and
  adds it to the Bazel text inventory. Not a lane-owned file. The change was needed because the stray-file and
  Starlark-subset checks would otherwise reject the new package.
- `.github/workflows/ci.yml`: `continue-on-error: true` removed from the `bazel` job. This is the final commit.

## Findings

- A local Bazel run rewrote one `usagesDigest` (the rules_nodejs `node` extension) in `MODULE.bazel.lock`. The
  Bazel version was the same 8.2.1. Hosted CI accepts the committed lock under `--lockfile_mode=error`. The change
  was not committed. Inference: the cause is local Bazel configuration, not this change.
- `scripts/BUILD.bazel` `workers` (data `//:repo_data`) can start `python -m condense` through tool_api, but it
  does not declare condense files. Workers resolve the real checkout, so this is a cache-correctness gap only. It
  was left alone because the file is outside this lane.
- The `BUILD.bazel` header comment in the repository root lists the sub-packages without condense. Only the
  comment is affected. It is outside this lane.
