# Condense caption style against the published v5 captions (2026-10-16)

Authority: Linear TIN-6573 (follow-up of TIN-6544, S4 milestone "Condense on real talks");
R-HOOK-CONVERGENCE-20261004 R-N13. The recordings, the archive, the private talk.toml files and every run
directory stay on the operator host. This receipt records hashes, counts, versions and measured numbers only.

## Result

With a `[captions]` section that states v5's caption style, condense writes the published v5 captions
**cue for cue within 1 frame: 520 of 520**, the same text and the same line breaks in all 520, on the seeded
tier (`edl.json` `3fdb0c65...`). Without the section, the captions are byte-identical to main's on every
private run checked. On v5's own hand-run edit list the same style writes the published SRT byte for byte.

## How v5 split its cues

The hand-run caption code is the archive's `review/v5/post.py` (sha256
`63edd8b7d596a51325cfc21d4d4248fb6318e5d3b16b1d60f23d90cba4d73505`); it wrote the published SRT
(`56855fd1...`) from `edl.v5.json` (`649bb675...`). Read from that code and measured on the SRT
(`2026-10-16-L11-captions-lines.py`):

| v5 rule | v5 | condense before (and default now) |
| --- | --- | --- |
| Which words | a word whose start plays in a speech or pause segment; a start inside a cut or a filler span drops it | a word the edit plays part of at speech speed (speech or a cut's kept edge); a word wholly in a pause is dropped |
| Filler words | kept as text: 18 filler words in the SRT | dropped by text (`is_filler`) |
| Word times | start through the time map; end at `end - 0.02` s, or start + 0.25 s when that is not played; words sorted | end at `end - 0.01` s, at least start + 0.05 s; starts never go backwards |
| Cue full | over 84 characters (2 x 42) | more than 2 wrapped lines of 42 |
| Cue ends | a gap over 1.2 s, a cue over 6 s (first start to last end), every sentence end | a gap over 1.0 s, a sentence end once the cue holds 21 characters |
| Line split | up to 42 characters on one line, else two lines broken at the last space before the middle + 8: longest line 49 | `textwrap` at 42 |
| Hold | at least 0.6 s; cut to 0.02 s before the next cue unless that cue starts within 0.3 s, then held and the next one pushed (23 pushed starts) | at least 1.0 s, always cut at the next cue's start |
| Card | one bracketed 2-line caption over the lost clip, 0.5 s inside each end of the 20 s card | no caption |
| Corrections | not in the SRT (0 `*` words); burned in by the overlay | not in the SRT |

Shape of the v5 SRT: 520 cues, 216 one-line and 304 two-line; 11 words (median, max 20) and 55 characters
(median, max 84) per cue; 1.796 s median, 0.291 s shortest, 19.0 s longest (the card); 277 cues end at a
sentence end; 49 gaps between cues over 1 s. The seeded run on main had 462 cues, 13 words and 71.5
characters median, 0 filler words and no card caption.

## What condense can now say

A typed `[captions]` section (`condense/config.py` `CAPTIONS`, checked by `check_captions` at load; an
unknown key, a bad choice, a negative time, `clear_s` without a larger `squeeze_s`, `fill = "chars"` with a
greedy split, `split = "balanced"` with other than 2 lines, a card caption for a clip that is not a card, and
an inset that leaves no time on the card are refused):

| Key | Default (the original style) | v5 |
| --- | --- | --- |
| `words` | `"spoken"` | `"start"` |
| `fillers` | `false` | `true` |
| `fill` | `"wrap"` | `"chars"` |
| `split` | `"greedy"` | `"balanced"` |
| `gap_s` | 1.0 | 1.2 |
| `max_s` | 0 (no limit) | 6 |
| `sentence_chars` | `caption_chars // 2` | 0 |
| `min_s` | 1.0 | 0.6 |
| `clear_s` | 0 | 0.02 |
| `squeeze_s` | 0 (always cut) | 0.3 |
| `cards` | none | the lost clip: two lines (private text) |
| `card_inset_s` | 0.5 | 0.5 |

`captions.build(cfg)` applies the section; `spoken()` and the new `started()` are the two word rules;
`split_lines()` the two line splits; `cues()` takes the style as keywords whose defaults are the original
ones. Synthetic tests: `condense/tests/test_captions.py` (9 new) and `test_config.py` (18 new cases).

Seeded tier, residual differences (all within 1 frame):

- 388 cues have both edges equal to the millisecond. 132 differ: before rounding (edges script), 124 by
  exactly 1 frame, 2 by 0.99 frame and 6 by 0.05 to 0.57 frame; none by more than 1 frame. Cause: the seeded
  edit list puts 639 of its 2427 shared segments one frame earlier than v5's (the quantiser's rounding ties,
  recorded in the v5 rebuild receipt). The SRT's millisecond stamps print the 126 edges of about 1 frame as
  34 ms (72) or 33 ms (54), and the other 6 as 2 to 19 ms; the committed compare script allows 1 frame + 1 ms
  for that rounding.
- The word-level line's 23 misses (495 of 518) are the 23 cues whose start v5 pushed to the previous cue's
  end (`squeeze_s`): their cue start is not their first word's time, in v5 or here. The 2 v5 cues without an
  aligned start are the card caption and one cue whose first token is punctuation, not a word.
- On `edl.v5.json` itself (edges script, `Timeline` swapped for the hand-run list), condense's v5 style
  writes an SRT byte-identical to the published one, so the style is reproduced exactly; the residual
  above is the edit list's.

Tool tier: 0 of 520. That is the analysis gap of the v5 rebuild receipt (gap 3): condense's own words and
events give a different edit (+194 frames) and different words (ratio 0.876), so no cue lines up. It is not a
caption-style gap.
