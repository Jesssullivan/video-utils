## Review fixes (2026-10-23)

The adversarial review of PR #37 reported 7 major and 7 minor findings. Its mutation
probes (unknown engine and table, confidential job, revoked consent, scope not
granted, malformed revisions, enums and links) all passed the first `check.py`.

- Rebased onto main `e308ee9`, keeping both `narrate-bench` and `narrate-dhall`
  imports; the original two commits (one added and one removed an empty scratch
  file) were squashed into one.
- `Engine.dhall`: an engine is hosted if its flag, profile or backend says so, and
  rented if its profile or backend says so; `consistent` checks profile against
  backend and the hosted flag, and `mayRunConfidential` requires it. Both bypasses
  the review evaluated (`GpuDirect`/`Hosted`, `MacMlx`/`RentedOpen`) are now
  asserted False in `policy-test.dhall`. `files : List { path, sha256 }` replaces
  `sha256 : List Text`; `sampleRateHz` is optional.
- `Job.dhall` gains `scope` and `allowHosted`.
- `check.py` checks job references, scope, revocation, allowed engines, hosted and
  confidential refusals (a Python port of the rule), validates the draft against
  the schema with a standard-library subset validator, and cross-checks drafts
  with `sources.json` (files, bytes, Hub digests when bound, stated upstream
  revision). `--self-test` applies 29 mutations, including every probe the review
  listed, and fails if any is accepted; `just narrate-dhall-check` runs it.
- Schema: `$defs/variant`, `runtime`, `upstream`, `revision` and `hf_repo`;
  entries and variants reject unknown keys.
- Draft: `vocab.json` added to both MLX variants; the Ming-only runtime note
  removed from VoxCPM2 and the Drama 3 GGUF variant; that variant records
  `upstream.revision` `dd64a85c`, its stated conversion source.
- `narrate-dhall-render` renders to a temporary file and moves it into place.
- The LUFS pronunciation note no longer claims first-use-only expansion.

Negative controls run by hand after the fixes: dropping `backendIsHosted` from
`isHosted` or `backendIsRented` from `isRented` made `policy-test.dhall` fail; a
deliberately broken `jobs.dhall` made the render recipe exit 1 with `jobs.json`
unchanged and no temporary file left.
