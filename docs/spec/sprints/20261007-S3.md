## Route map (private app)

| Route | Purpose | Data / API |
| --- | --- | --- |
| `/` | Clip library | `GET /api/v1/sources` |
| `/upload` | Admit or upload a take | `POST /api/v1/uploads` (resumable parts later) |
| `/sources/[id]` | Clip overview: probe summary, runs, jobs | `GET /api/v1/sources/{id}` |
| `/sources/[id]/capture` | Review the fan-noise capture interval bound to the source hash; the first 5 s are never auto-confirmed | capture_profile / noise jobs |
| `/sources/[id]/process` | Preview vs full-take render; separate cleanup, tone (incl. bounded shelf option), dynamics knobs; FULLER default with required reviewed interval; no 80 Hz high-pass, no notch default | denoise / apply_capture_profile / tone jobs |
| `/runs/[id]` | Run graph: stages, signal versions, invalidation, evidence | `GET /api/v1/runs/{id}` |
| `/runs/[id]/compare` | Matched-level A/B (source / denoise / FULLER / trials) | tone_ab |
| `/runs/[id]/review` | Phrase/BPM overlays, triaged flags, Mark here labelling (user vs detector distinct), spectrogram, per-phrase timing as measurements | annotations-v2, phrase_anchor, phrase_timing, flags_triage, lowreg spectrogram |
| `/runs/[id]/deliver` | Share MP4, WAV, marker files (FCPXML/Resolve export with import unverified) | share_export, editor_marker_export, marked_compact |
| `/jobs`, `/jobs/[id]` | Queue and job state, cancel/retry | jobs API |
| `/tools` | Capabilities, 40 typed tools, model lanes and gate states | `GET /api/v1/capabilities` |

## Limits that stay explicit

Hosting and Cloudflare/cluster changes are prepared as reviewed manifests and plans; applying them to Cloudflare or the RKE2 cluster is an outward-facing action that needs a separate operator go. Real-take media never leaves operator-controlled hosts (V6). Model downloads stay explicit and hash-bound. No note-correctness or missed-note verdicts.
