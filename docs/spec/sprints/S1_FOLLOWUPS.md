# Evidence priorities after S1

These are queued follow-ups to the existing core roadmap, not additional active
goals or default changes. S1's finite experimental outcomes are preserved.

| Priority | Deliverable | Completion evidence |
|---|---|---|
| 1 | Continuous-riff phrase proposal benchmark | Preregister genuinely new, back-to-back high-occupancy motifs, syncopated palm mutes, legato and phrase transitions before generating held-out data. Score pair IoU, endpoint errors and negatives independently. S1's quiet-delimited4/4 result cannot qualify this distribution. |
| 2 | Nonlinear denoiser source-null artifact gate | Measure absolute generated low-band content when the known musical fundamental is absent, alongside relative retention. Preserve counterfactual interaction and collision exclusions; tiny-reference gain ratios cannot demonstrate recovered notes. |
| 3 | Sparse operator review corpus | Use the separate v2 store for actual source-timed points/spans with literal user assertions, intent and detector hypotheses kept distinct. Keep every derivative in its source family, and keep uncovered intervals unknown. No automatic negative labels or musical verdicts. |
| 4 | Real practice evaluation | Obtain reviewed phrase endpoints and issue examples through the local player, then compare untouched detector proposals against those sparse observations. Report coverage and clock alignment before performance precision/recall. |

New model acquisition, hosted processing, AU/Logic execution and native editor
import retain their separate queued milestones. An accepted restored master does
not establish any of those capabilities.
